This game was originally built for a friend of mine 😁.
It's basically a roguelike card game, that is heavily inspired from the game mechanics of **Uno**, and other roguelikes. Check the feature list below for the game mechanics and stuff!

## Feature List

| Feature                         | Description                                                                                                                    | Version |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ------- |
| **Uno-Inspired Game Mechanics** | Game rules contains classic Uno rules.                                                                                         | v0.1.0  |
| **LAN Multiplayer**             | Players can join other players locally (via QR code, or manual IP input). Supports cross-play.                                 | v0.4.0  |
| **Online Multiplayer**          | Players can also join other players _online_ (via room codes). The server is situated in **Southeast Asia**, in **Singapore**. | v0.6.0  |
| **Relics**                      | Items that are obtained through the _chest card_, which has varying effects on the game.                                       | v0.12.0 |
| **Events**                      | Game events where it may trigger through exhausting the _pile deck_ (the remaining cards to be drawn from), or from relics.    | v0.13.0 |
