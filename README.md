# Ishi: The Unolike Roguelike

This game is built specifically for a friend of mine 😁.
It's basically a roguelike card game, that is heavily inspired from the game mechanics of **Uno**, **Balatro**, and other roguelikes.

## Feature List

| Feature | Description | Version |
| ------- | ----------- | ------- |
| **Uno-Inspired Game Mechanics** | Game rules contains classic Uno rules. | v0.1.0 |
